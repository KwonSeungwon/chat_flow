## 확인 기준 (사용자가 보는 결과)
- 던전 배틀 화면에 내 HP 바(100)와 몬스터 HP 바가 실제 수치로 줄어든다. 정답이면 "15 데미지", 3연속 이상이면 "치명타! 30", 오답이면 "몬스터의 공격! 25".
- 일반 몬스터는 정답 2번(치명타면 1번)에 쓰러지고, 3마리를 잡으면 보스(HP 90)가 나온다. 보스 HP를 0으로 만들면 클리어, 내 HP가 0이면 실패.
- 마을 화면의 "도감"에서 잡은 몬스터(정답을 한 번이라도 낸 주제)가 보이고, 못 잡은 몬스터는 ???로 보인다. 잡은 몬스터를 누르면 그 주제 문제로 복습 배틀(최대 5문제, 실패 없음)을 하고 "n/m 정답"을 보여 준다.
- 옛 Android 클라이언트(3.0.0)는 `hearts`/`cleared`/`failed`만 읽어도 계속 동작한다.

## 규칙
| 값 | 수치 |
| --- | --- |
| 내 최대 HP | 100 |
| 일반 몬스터 HP / 공격 | 30 / 25 |
| 보스 HP / 공격 | 90 / 34 |
| 내 공격 | 15, 연속 정답(이번 포함) 3 이상이면 치명타 ×2 |
| 보스까지 처치 수 | 3 (기존 5) |
| `hearts`(호환) | ceil(hp × 3 / 100) |
| 복습 | 주제의 승인 문제 최대 5개(복습 기한 지난 것 먼저), 몬스터 HP = 15 × 문제 수, 치명타·피해 없음, 다 풀면 끝 |

같은 몬스터와 싸우는 동안 다음 문제는 그 몬스터 주제의 안 푼 문제를 먼저 낸다.
